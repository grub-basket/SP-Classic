# Stashpad Classic 0.102.25 — retired

**Stashpad Classic is retired.** Obsidian's insider APIs are now in the public
release, so regular **Stashpad** works for everyone again — you no longer need Classic.

**Switch to Stashpad:** it's on the Obsidian community store
([store page](https://community.obsidian.md/plugins/stashpad)) — open **Settings →
Community plugins → Browse** and search for **Stashpad**. It has everything Classic
has and more (encryption, tasks, the full mobile layout), and it's actively maintained.

This release carries no code changes — it's the same frozen 0.102.24 build, published
so the retirement notice reaches the store. Classic stays installable for anyone who
still wants it, but it won't get further updates.

_Until the next insider-API mishap, anyway. See you then._ 🙂
